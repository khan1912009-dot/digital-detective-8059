## ASCII

ASCII stands for American Standard Code for Information Interchange.

It assigns a numeric value to each character.

Examples:
A = 65
a = 97
B = 66
0 = 48

ASCII helps computers represent text using numbers.

## UTF-8

UTF-8 stands for Unicode Transformation Format - 8 bit.

It is a character encoding system that supports characters from
many languages, symbols and emojis.

Examples:
A - English character
न - Hindi character
😊 - Emoji

Difference:
ASCII supports 128 standard characters, while UTF-8 supports
a much larger range of characters from different languages.
