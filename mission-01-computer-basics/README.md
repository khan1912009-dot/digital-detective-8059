# Mission 1 — Know Your Computer

## 1. Task / objective

The objective of this mission is to understand how a computer works using the Input, Processing, Output and Storage (IPOS) model.

This mission also focuses on identifying hardware and software, understanding their purposes, and recognising computer-based systems used in everyday life.

## 2. Work completed

### Task 1.1 — Trace one activity using IPOS

**Activity chosen: Typing and saving a document on my Mac**

| Stage | What happens in my example? | Hardware / component involved |
|---|---|---|
| Input | I type words using the keyboard and use the trackpad to interact with the document editor. | Keyboard and trackpad |
| Processing | The CPU processes the keyboard input while RAM temporarily holds the document data being used by the application. | CPU and RAM |
| Output | The typed text appears on the screen, allowing me to read and edit it. | Display |
| Storage | When I save the document, its contents are stored as a file on the computer. | SSD |

**Explanation of the IPOS process:**

When I type a document, the keyboard sends input to the computer. The processor works with the operating system and document editor to process my keystrokes. The result appears on the screen as text. When I save the document, the file is stored on the SSD so that I can open it again later.

This activity helped me understand how different computer components work together to complete a simple task.

### Task 1.2 — Identify hardware and software

**Hardware examples**

| Item / software name | Hardware or software? | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text and commands into the computer. |
| CPU | Hardware | Not applicable | Executes instructions and processes data. |
| RAM | Hardware | Not applicable | Temporarily holds data and instructions being used by running programs. |
| SSD | Hardware | Not applicable | Stores files, applications and operating system data. |
| Display | Hardware | Not applicable | Shows text, images and other visual information. |
| Trackpad | Hardware | Not applicable | Controls the pointer and allows interaction with applications. |

**Software examples**

| Item / software name | Hardware or software? | Software type | Purpose |
|---|---|---|---|
| macOS | Software | Operating system software | Manages hardware resources, files, memory and running applications. |
| Visual Studio Code | Software | Application software | Used to write and edit code and project files. |
| Safari | Software | Application software | Used to browse websites and access online information. |
| Terminal | Software | Utility software | Provides a command-line interface for interacting with the operating system. |
| Disk Utility | Software | Utility software | Helps inspect and manage storage devices and disks. |

**My understanding of hardware and software:**

Hardware refers to the physical parts of a computer that can be touched, such as the keyboard, processor and storage device.

Software refers to programs and instructions that tell the computer what to do.

Operating system software manages computer resources, application software helps users perform tasks, and utility software provides tools for managing or maintaining the system.

Hardware and software depend on each other. Hardware performs physical operations, while software provides the instructions needed to perform useful tasks.

### Task 1.3 — Computer systems around me

| System | Main purpose | One input | One output |
|---|---|---|---|
| ATM | Allows customers to perform banking transactions. | PIN entered using the keypad. | Cash dispensed or a transaction message displayed. |
| Smart TV | Displays entertainment and digital content. | Commands from a remote control. | Video and audio. |
| Traffic signal controller | Controls traffic movement at road intersections. | Information from a vehicle detection sensor. | Red, yellow and green traffic lights. |

**Explanation:**

An ATM uses input from a customer to process banking requests and provide a result.

A smart TV receives commands from a remote control, processes them and displays the selected content.

A traffic signal controller uses programmed instructions and, in some systems, sensor information to control traffic lights.

These examples helped me understand that computer systems are used in many devices beyond laptops and mobile phones.
