
# Mission 2: Terminal Practice

## Objective
To learn basic Terminal commands and understand how to manage files and folders using the command line.

## Work Completed

1. Created a practice folder and a text file.
2. Used `echo` to write text into a file.
3. Used `>` to overwrite file content.
4. Used `>>` to append text without deleting existing content.
5. Used `cat` to display file contents.
6. Used `cp` to create a backup copy.
7. Used `mv` to rename the backup file.
8. Used `pwd` to display the current directory.
9. Used `ls` to list files and folders.
10. Used `cd ..` to move to the parent directory.
11. Used `ls -lah` to display detailed information, including hidden files.
12. Used `ls -lah | head -n 5` to display only the first five lines.
13. Checked the installed Homebrew version using `brew --version`.

## Commands Learned

| Command | Purpose |
|---|---|
| pwd | Shows current directory |
| ls | Lists files and folders |
| cd | Changes directory |
| mkdir | Creates a folder |
| touch | Creates an empty file |
| echo | Prints text |
| cat | Displays file contents |
| cp | Copies files |
| mv | Moves or renames files |
| ls -lah | Shows detailed file information |
| head | Displays the first lines |
| brew --version | Checks Homebrew version |

## What I Understood

- `>` replaces existing file content.
- `>>` adds new content without removing old content.
- `cp` creates a copy while keeping the original.
- `mv` moves or renames files.
- A pipe (`|`) sends the output of one command to another command.
- Homebrew is a package manager used to install and manage software on macOS.

## Difficulties Faced

Initially, I was learning how to navigate folders and use Terminal commands. I practised each command step by step and verified the results.

## Result

Successfully completed the basic Terminal practice and learned how to create, view, copy, and rename files.
