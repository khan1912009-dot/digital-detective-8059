# The Digital Detective

## About This Project

This repository contains my SNAI Digital Detective assignment. The aim of this project is to understand how computers work through practical activities and experiments.

Throughout this assignment, I will explore computer hardware and software, Terminal commands, operating systems, Python programming, number systems, Git, GitHub, and computer networks.

## Project Workflow

Each mission will be completed in sequence. I will perform the required activities, document my observations and understanding in the mission's README.md, and create a separate Git commit for each completed mission.

After committing, I will push the changes to GitHub and verify that they are visible before starting the next mission.
