LAN (Local Area Network)

A network connecting devices in a small area, such as a home, computer lab or college campus.

MAN (Metropolitan Area Network)

A network that connects devices or smaller networks across a city.

WAN (Wide Area Network)

A network that connects devices across large geographical areas, such as different countries. The Internet is an example.

## DNS (Domain Name System)

DNS converts human-readable domain names into IP addresses.

Example:
google.com is a domain name. DNS helps find its IP address.

## Router

A router connects different networks and forwards data
between them.

Example:
A home Wi-Fi router connects devices to the internet.

## Protocol

A protocol is a set of rules that allows devices to communicate.

Examples:
HTTP - Transfers web pages.
HTTPS - Provides secure web communication.
TCP - Provides reliable data delivery.
IP - Handles addressing and routing.

## Packet Switching

Packet switching is a method of transferring data by dividing
it into smaller pieces called packets.

These packets travel through a network and are reassembled
at the destination.

## Client-Server Architecture

Client:
A client is a device or application that requests services
or information from a server.

Server:
A server is a computer that receives requests and provides
services or information.

Example:
When I open YouTube, my browser sends a request to YouTube's
server. The server processes the request and sends back the
required information.

## Networking Commands Practised

### 1. Ping

Command:
ping -c 4 example.com

Purpose:
This command sends 4 test packets to example.com to check
network connectivity and response time.

### 2. Nslookup

Command:
nslookup example.com

Purpose:
This command checks DNS information and finds the IP address
associated with a domain name.

## What Happens When I Open a Website?

Example: https://www.google.com

Step 1: I open my web browser and type
https://www.google.com.

Step 2: The browser checks the website address.

Step 3: DNS finds the IP address associated with the domain name.

Step 4: The browser connects to the website's server using
the network and HTTPS protocol.

Step 5: The browser sends a request to the server.

Step 6: The server processes the request and sends back
the required files and information.

Step 7: The browser displays the website on my screen.

Conclusion:
Networking allows my computer to communicate with servers
and access websites through the internet.
