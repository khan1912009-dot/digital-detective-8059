## What I Learned

1. `git status` checks the current working state.
2. `git log` shows previous commits.
3. Git branches allow separate development.
4. `git switch -c` creates and switches to a new branch.
5. `git add` stages changes.
6. `git commit` saves changes locally.
7. `git push` uploads changes to GitHub.
8. A Pull Request proposes merging one branch into another.
