
# Mission 3: Understanding the Operating System

## Objective
To understand the operating system, system information, storage, running processes, file paths, and file permissions.

## 1. System Information

I used the following commands on my Mac:

- `sw_vers` – Checked the macOS name and version.
- `uname -m` – Checked the processor architecture.
- `df -h` – Checked disk storage information.
- `whoami` – Checked the current user account locally. Personal username is not included for privacy.

## 2. Running Processes

Command used:

`ps aux | head -n 10`

A process is a program that is currently running on a computer.

PID stands for Process ID. It is a unique number assigned to each running process.

## 3. File Paths

- Absolute path: The complete location of a file or folder, starting from the root directory.
- Relative path: The location of a file or folder in relation to the current directory.

Commands practised:

- `pwd` – Displays the current directory.
- `ls practice` – Lists the contents of the practice folder.

## 4. File Permissions

Command used:

`ls -l practice`

File permissions determine who can read, write, or execute a file.

- Read (r): Allows viewing a file.
- Write (w): Allows modifying a file.
- Execute (x): Allows running a file as a program.

## 5. Responsibilities of an Operating System

| Responsibility | Explanation |
|---|---|
| Process Management | Manages running programs and processes. |
| Memory Management | Allocates and manages computer memory. |
| Device Management | Manages hardware devices such as keyboards and printers. |
| File Management | Organises files and folders. |
| User Interface | Provides ways for users to interact with the computer. |
| Security | Helps protect files, accounts, and system resources. |

## 6. What I Learned

I learned how to check operating system information, processor architecture, storage usage, and running processes. I also understood PIDs, absolute and relative paths, and file permissions.

## 7. Result

Successfully completed the operating system exploration tasks and learned about the main responsibilities of an operating system.
